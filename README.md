# Enterprise AI Hub

An enterprise-grade AI platform combining Retrieval-Augmented Generation (RAG), multi-agent orchestration, persistent memory, and secure document management.

## Features

- **RAG Pipeline:** Ingest, process, and retrieve company documents.
- **Multi-Agent System:** Supervisor agents, specialized sub-agents, and intelligent routing.
- **Memory Management:** Short-term memory (STM) and long-term memory (LTM).
- **Secure Access:** User authentication, role-based authorization, and protected APIs.
- **Conversation History:** Persistent, user-specific chat sessions and messages.
- **Production Readiness:** Evaluation, observability, and cloud deployment.

## Tech Stack

Python · FastAPI · Google ADK · PostgreSQL · pgvector · Docker · GCP

## Architecture

Modular backend with dedicated components for API management, agent orchestration, document ingestion, retrieval, memory, and data storage.

🚧 In active development.

## Goal

Build a secure, scalable enterprise AI platform demonstrating practical AI engineering, RAG, agentic AI, and production system design.
